# Python language

A progressive tutorial on core Python language features, from basic syntax to intermediate programming techniques.

- Python 3.10 or later.
- No external libraries required.
- Follow the topics in order. Examples simulate a Python REPL session without prompts. Results and printed output appear directly below the corresponding code. Enter only the code, not the displayed output. Blank lines separate successive commands and their results; output appears immediately after its command.
- Read the examples within each document in order, using the same Python REPL session. In the REPL, press Enter on an empty line to finish an indented block. Tracebacks are shortened for readability.
- Exercises: [python-edu/exercises](https://github.com/python-edu/exercises).
